# SQL Sales Analysis Project

## Project Overview
This project analyzes sales data using SQL queries in MySQL.

## Objectives
- Retrieve and filter sales records using SELECT and WHERE.
- Analyze revenue using SUM, AVG, and COUNT.
- Group and sort sales data.
- Identify the top 10 customers.
- Calculate average order value.
- Perform INNER JOIN and LEFT JOIN operations.
- Use subqueries and CASE statements.
- Analyze sales by category and region.

## Tools Used
- MySQL Server
- MySQL Workbench
- SQL

## Main File
`sales_analysis.sql` contains the SQL queries used for the analysis.
